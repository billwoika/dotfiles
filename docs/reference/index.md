# Reference

Start here. This section covers everything you need to install,
configure, and maintain the dotfiles — the practical information
bound directly to the repository artifact.

## In this section

- **[Repository Structure](repository.md)** — the full file layout,
  what `bootstrap.sh` does, and the symlinked-vs-copied distinction.
- **[Fedora Workstation Setup](fedora-setup.md)** — machine-level
  optimization for a fresh Fedora install: dnf, firmware, codecs,
  SELinux, firewall, GNOME tuning, and developer prerequisites.
  Run this before the Onboarding Runbook.
- **[Onboarding Runbook](onboarding.md)** — step-by-step new-machine
  setup from clone through validation.
- **[Customization](customization.md)** — the placeholder string
  convention, what to substitute when forking, version notes, and
  the relationship between this site and earlier framework versions.
- **[Test Suite](test-suite.md)** — the 30-test POSIX test suite for
  the `~/.profile` shim, with test groups and key tests explained.
- **[Troubleshooting](troubleshooting.md)** — common issues with mise,
  git identity, SSH, shell startup, and direnv.
