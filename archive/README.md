# Archive

Earlier versions of the Developer Environment Framework, preserved for
historical reference.

The framework was originally a Word document manuscript. As of v2.7, the
canonical source moved to MkDocs (the `docs/` directory). The frozen
snapshots here document the state of the manuscript at each major
version transition.

| File | Description |
|------|-------------|
| `v2.7-snapshot.docx` | The full 209-page manuscript at the moment of MkDocs migration. Final Word-format version. |

These archives are read-only. New content goes in the docs site.
